# Formula 1 Repository Project 🏎️

## Опис
Навчальний проєкт із дисципліни **"Програмування на стороні сервера"**.  
Реалізовано патерн **"Репозиторій"** у Django для роботи з базою даних Formula 1.

## Реалізовані функції
- Перегляд усіх записів (`list_all`)
- Пошук за ID (`get_by_id`)
- Додавання нових записів (`add`)
- Видалення записів (`delete_by_id`)
- Вивід результатів гонок із пов’язаними таблицями
- (Додатково) Редагування записів (`update_by_id`)
